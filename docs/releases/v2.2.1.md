# SoundBoardFasaFiso v2.2.1

SoundBoardFasaFiso v2.2.1 is a focused Voice Effects maintenance release that adds a natural, pitch-free Vocal Weight control on top of the v2.2.0 voice changer.

## Vocal Weight

- Adds an independent **Vocal Weight** slider to the embedded Voice Effects page.
- Reinforces voiced low-frequency chest weight without lowering pitch or shifting formants.
- Uses parallel low-band compression and restrained harmonic density instead of a second pitch layer.
- Avoids reinforcing the boxy `400–800 Hz` region and backs off automatically on unvoiced consonants and silence.
- Smooths live parameter changes without adding another processing thread or algorithmic latency.

Vocal Weight is a general-purpose narrator, deep-voice and character tool. It is not an identity-cloning system; matching a specific person's vocal identity would require a separate voice-conversion model and is outside this release.

## Compatibility

- Existing v2.2.0 configurations remain valid.
- Existing user presets without a Body value load with Vocal Weight set to zero.
- Built-in presets keep their existing sound unless Vocal Weight is adjusted manually.
- WebRTC AEC3, stereo crosstalk cancellation, RNNoise, microphone dynamics and output routing remain in the same order.
- The official package remains portable and standalone with no new runtime dependency, service or installer.

## Real-time behavior

- Fixed Voice Effects latency remains `16 ms`.
- The microphone callback remains free of file access, device queries, heap allocation and mutex waits.
- Vocal Weight runs inside the existing microphone-processing worker and uses smoothed block-boundary settings updates.

## Validation

The release is covered by the existing 33-test Windows suite, including Voice Effects settings, config compatibility, preset persistence, processor behavior, robustness, microphone runtime, AEC3, crosstalk cancellation and RNNoise.

The final release build should be produced with WebRTC AEC3 enabled and the `VerifyPortableRelease` target before tagging.
