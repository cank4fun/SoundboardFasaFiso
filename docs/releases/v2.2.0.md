# SoundBoardFasaFiso v2.2.0

SoundBoardFasaFiso v2.2.0 adds a local, low-latency Voice Effects / Voice Changer pipeline while preserving the v2.1.2 AEC, crosstalk-cancellation and routing foundation.

## Voice Effects / Voice Changer

- The new Voice Effects tab is embedded in the main control panel and does not open a separate popup.
- Pitch can be adjusted from `-12` to `+12` semitones and formant from `-6` to `+6` semitones independently. Speech duration and speaking speed remain unchanged.
- Built-in presets include Deep / Heavy, High / Nasal Rap, Dark Vocal, Radio, Robot and Tiny / High Voice, together with a Custom mode.
- Character EQ, drive saturation, dry/wet mix and output gain are available for live adjustment. Radio, Robot and Tiny use dedicated character stages.
- The speech-oriented hybrid engine combines phase-locked spectral processing, pitch-synchronous voiced processing, transient handling and a delayed natural path for unvoiced material.
- Dry and wet paths are latency-aligned. The Voice Effects stage reports a fixed 16 ms DSP latency at the required 48 kHz processing rate.

## Presets and hotkeys

- Up to 32 named user presets can be saved, updated and deleted directly in the embedded tab.
- User preset data is validated and stored in the portable `config.txt`; malformed preset data falls back safely.
- Previous preset, next preset and Voice Effects bypass are available as configurable global hotkeys.
- Built-in and user presets participate in the same cycling order.

## Real-time safety and diagnostics

- Voice Effects settings are transferred lock-free and applied on the existing microphone worker at 10 ms block boundaries.
- The processing path performs no heap allocation, file access, device query or mutex wait in the real-time block operation.
- Inline telemetry reports average and maximum processing time, deadline misses, queue peak, dropped input frames, rejected setting updates and effective DSP latency.
- Automated tests cover preset transitions, bypass, reset, invalid samples, clipping limits, deterministic state, runtime delivery and the 10 ms processing budget.

## Existing microphone pipeline

The effective microphone order remains:

```text
Physical microphone
→ stereo crosstalk cancellation
→ WebRTC AEC3
→ high-pass filter
→ RNNoise
→ Voice Effects
→ AGC
→ compressor
→ Voice Effects output gain
→ limiter
→ configured main/monitor routing
```

Voice Effects does not replace or bypass AEC3, crosstalk cancellation or RNNoise. Global microphone-processing bypass retains the existing original-stereo behavior.

## Portable release

The official ZIP remains self-contained. It requires no installer, administrator rights, Visual C++ Redistributable, .NET, Python, CMake, vcpkg, background service or separately installed DSP runtime. Optional VB-CABLE routing remains external and is not bundled.

Official release files are currently unsigned. Verify `SoundBoardFasaFiso-v2.2.0-windows-x64-portable.zip` against the attached SHA-256 file before running it.

## Upgrade notes

- Preserve a reviewed copy of the existing `config.txt` and personal `sounds` folder before replacing program files.
- Existing configurations without Voice Effects keys load with the feature disabled.
- Voice Effects requires the 48 kHz microphone-processing runtime. The tab reports when that runtime is unavailable.
- The final preset loudness values were tuned against the v2.1.2 microphone-filter baseline; microphone hardware and speaking level can still require small output-gain adjustments.
