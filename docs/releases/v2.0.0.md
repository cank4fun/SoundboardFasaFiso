# SoundBoardFasaFiso v2.0.0

This is the first stable v2 release of SoundBoardFasaFiso.

## Highlights

- Native single-window Win32 control panel with light and dark themes
- Independent main and monitor playback devices with separate volume and mute controls
- Physical microphone capture and routing to the main output, monitor output, or both
- Visual hotkey and sound-binding editor with restart, overlap, toggle and loop modes
- Safe live configuration with validation and rollback
- Automatic recovery after audio-device disconnects
- Persistent session logs, optional Windows startup and optional update checks
- Portable Windows x64 ZIP with no installer or external runtime requirement

## From the release candidates

The stable release includes the fixes from `2.0.0-rc.2`, including startup with no usable sound bindings and keeping the control panel available when configured sound files are missing.

## Windows security notice

The official GitHub artifacts for `v2.0.0` are **unsigned**. Microsoft Defender SmartScreen may show an unknown-publisher warning, and Windows 11 Smart App Control can block a new unsigned executable. Do not disable Windows security permanently to run the application.

Download the ZIP only from this GitHub Release and compare it with the attached `.sha256` file:

```powershell
Get-FileHash .\SoundBoardFasaFiso-v2.0.0-windows-x64-portable.zip -Algorithm SHA256
```

A matching SHA-256 confirms that the ZIP is identical to the published release asset; it does not provide publisher authentication or replace code signing.

## Scope

This release contains the stable v2.0 feature set. Experimental v2.1 microphone processing, RNNoise, AGC and WebRTC AEC3 work is not included.
