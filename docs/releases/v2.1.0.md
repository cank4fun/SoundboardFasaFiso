# SoundBoardFasaFiso v2.1.0

SoundBoardFasaFiso v2.1.0 expands the portable native Windows soundboard with verified media import, an embedded WAV editor, richer playback control and an opt-in microphone-processing chain with WebRTC AEC3.

## Highlights

- Background URL import and local-media conversion to WAV
- Bundled `yt-dlp`, Deno, FFmpeg and ffprobe binaries pinned and verified with SHA-256
- Embedded WAV editor with asynchronous load/save and monitor-output preview
- Waveform navigation, seek, zoom, selection and precision trim
- Cut, copy, paste, undo, redo, gain, normalize, fades, mono conversion and silence tools
- `I` and `O` shortcuts for setting trim boundaries at the playhead
- Active playback sessions with pause/resume, seek, stop and temporary volume
- Optional microphone HPF, RNNoise, AGC, compression, limiting and WebRTC AEC3
- Refined editor controls, responsive toolbar layout, themed native controls and inline validation
- Fresh full-suite test target and hardened portable-package verification

## Portable release

The ZIP is self-contained and requires no installer, administrator rights, Visual C++ Redistributable, .NET, Python, CMake or vcpkg. Extract the complete folder and run `SoundBoardFasaFiso.exe`.

The official package includes WebRTC AEC3, verified media tools, dependency notices, safe default configuration, example sounds and `portable.flag`, which keeps mutable application data inside the extracted folder.

## Windows security notice

The official GitHub artifacts for `v2.1.0` are **unsigned**. Microsoft Defender SmartScreen may show an unknown-publisher warning, and Windows 11 Smart App Control can block a new unsigned executable. Do not disable Windows security permanently to run the application.

Download the ZIP only from this GitHub Release and compare it with the attached checksum:

```powershell
Get-FileHash .\SoundBoardFasaFiso-v2.1.0-windows-x64-portable.zip -Algorithm SHA256
```

The result must match the hash stored in `SoundBoardFasaFiso-v2.1.0-windows-x64-portable.zip.sha256`. A matching checksum confirms file integrity; it does not replace publisher authentication or code signing.

## Upgrade notes

- Extract v2.1.0 into a new folder for the first portable test.
- Copy personal sounds and reviewed configuration changes only after the clean package starts successfully.
- Microphone processing and echo cancellation remain disabled by default.
- URL import uses only the tools bundled inside the portable `tools` directory and does not install them into `PATH`.
