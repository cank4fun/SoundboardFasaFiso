# SoundBoardFasaFiso v2.1.2

SoundBoardFasaFiso v2.1.2 hardens WebRTC AEC3 for headsets whose USB codec or acoustic path leaks playback directly into the microphone capture stream.

## Fixed and improved

- The selected monitor output now reaches AEC3 as an immediately active stereo render reference; left/right information is no longer discarded before echo analysis or delayed behind content detection.
- A device-independent stereo crosstalk stage automatically discovers the render-to-capture offset with GCC-PHAT, learns only leakage models that measurably improve the microphone signal, and applies a double-talk-aware residual blocker after AEC3.
- A validated high-suppression AEC3 profile targets strong residual playback bleed while retaining the default near-end/double-talk tuning.
- Endpoint and process-excluded loopback underruns now bypass AEC safely instead of feeding a false all-zero reference block.
- Post-render WASAPI loopback uses AEC3's internal delay estimator rather than a fixed delay hint that cannot match every USB audio device.
- Existing soundboard-only fallback behavior remains available when system loopback cannot be initialized.

## Portable release

The ZIP is self-contained and requires no installer, administrator rights, Visual C++ Redistributable, .NET, Python, CMake or vcpkg. Extract the complete folder and run `SoundBoardFasaFiso.exe`.

## Upgrade notes

- Replace the v2.1.1 program files with the v2.1.2 portable release while preserving reviewed `config.txt` and personal sounds.
- Keep the monitor output set to the same physical headphones or speakers used by voice chat, games and media playback.
- Keep voice-chat input set to the application's virtual main mix (`CABLE Output` in the common VB-CABLE setup), not the physical microphone endpoint.
- Strong AEC is intended to suppress hardware playback bleed; a true software routing loop should still be corrected at the device-routing layer.
