# SoundBoardFasaFiso v2.1.1

SoundBoardFasaFiso v2.1.1 is an AEC hotfix for the v2.1 microphone-processing release.

## Fixed

- WebRTC AEC3 now receives voice-chat, game and other system audio from the selected physical monitor output through WASAPI loopback.
- Soundboard monitor playback remains covered by the AEC reference.
- Microphone monitoring and temporary test monitoring are prevented from feeding the user's own processed voice into a full endpoint reference.
- If endpoint loopback cannot start, the application falls back to a process-excluded system reference when possible and then to the previous soundboard-only reference.
- The loopback queue is bounded to keep stale system audio from drifting away from the microphone stream.

## Portable release

The ZIP is self-contained and requires no installer, administrator rights, Visual C++ Redistributable, .NET, Python, CMake or vcpkg. Extract the complete folder and run `SoundBoardFasaFiso.exe`.

## Upgrade notes

- Replace the v2.1.0 program files with the v2.1.1 portable release while preserving reviewed `config.txt` and personal sounds.
- Keep the monitor output set to the physical headphones or speakers that carry voice-chat audio.
- Headphones are still recommended. AEC reduces acoustic leakage but cannot repair a routing loop where a virtual output is selected as the microphone input.
