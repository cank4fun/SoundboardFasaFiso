# SoundBoardFasaFiso v2.3.0

SoundBoardFasaFiso v2.3.0 introduces **Classic Voice Engine 2**, a rebuilt
local Voice Effects pipeline focused on deterministic speech processing,
real-time safety, portable presets and compact control inside the existing
single-window application.

Classic Voice Engine 2 does **not** use AI inference, model files, network
access, a cloud service or a new runtime dependency.

## Speech-aware voice core

- Adds an allocation-free Speech Analysis Core for pitch, voicing, speech
  activity, onset/transient detection and a reusable smoothed spectral envelope.
- Adds Pitch Engine 2 with a pitch-synchronous dual-grain path blended with the
  existing phase-locked spectral processing.
- Adds Formant Engine 2 with independent, bounded log-domain envelope warping.
- Replaces the previous body stage with Vocal Weight Engine 2 for analysis-aware
  chest reinforcement without changing pitch or formants.
- Preserves consonants and attacks by reducing voiced processing when speech is
  unvoiced or transient-heavy.

## Voice polish and modular rack

- Adds an adjustable three-band parametric EQ with low/high shelf frequencies,
  mid frequency and mid Q.
- Adds a split-band de-esser, speech-aware gate/expander and soft-knee
  compressor.
- Each module can be bypassed independently.
- EQ, de-esser, gate and compressor can be reordered from the embedded rack.
- Live rack changes use a controlled transition instead of switching filter and
  detector state abruptly.

## Portable preset exchange

- Adds versioned `.sbffvoice` import/export in the portable `voice-presets`
  folder.
- Preserves every Voice Effects parameter, module state and rack order.
- Validates UTF-8, file size, fields and checksum before importing.
- Uses transactional overwrite with recovery instead of replacing a valid
  preset with a partial write.
- Existing v2.2.x configurations and user presets continue to load with neutral
  defaults for fields they do not contain.

## Diagnostics and real-time behavior

- Adds an inline deterministic Voice Engine self-test covering seven processor
  contracts without opening a microphone or audio device.
- Keeps Voice Effects after RNNoise and before AGC.
- Keeps the fixed Voice Effects latency at `768 samples` / `16 ms` at 48 kHz.
- Keeps settings delivery at block boundaries and the processing path free of
  file access, device queries and mutex waits.
- Preserves the existing WebRTC AEC3, stereo crosstalk cancellation, routing and
  portable standalone architecture.
- Keeps the public version and vcpkg manifest version locked together at
  configure time so stale release metadata cannot produce an official build.
- Removes the obsolete AEC3 spike compatibility switch; release and development
  builds use the production AEC3 options documented in the repository.

## Release validation

The release build must be produced with WebRTC AEC3 enabled, warnings treated
as errors, the complete CTest suite built fresh, and `VerifyPortableRelease`
completed before tagging. The final release checklist also includes the inline
`7/7` self-test, preset import/export round-trip and physical bypass, preset,
rack, AEC and routing comparisons.

## Download verification

Official release files are currently unsigned. Verify
