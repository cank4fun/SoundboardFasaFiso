MEDIA TOOLS DIRECTORY
=====================

Official standalone packages will place verified yt-dlp, FFmpeg and ffprobe
executables in this folder when URL import is enabled. SoundBoardFasaFiso does
not install tools system-wide, modify PATH, or require administrator rights.

Do not download random executable files into this folder. Use only the media
manager built into SoundBoardFasaFiso or files from the official release.
